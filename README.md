# TaskFlow

> Une application Web simple pour planifier et gérer des tâches d'étude et de travail.

## À propos

**TaskFlow** est une petite application Web construite pour répondre au besoin d'**Oracles**, une persona représentant une étudiante souhaitant mieux organiser ses activités d'étude et de travail.

L'application repose sur une idée simple :

> Planifier une tâche, définir son créneau horaire, préciser son objectif si nécessaire et suivre son état d'avancement.

TaskFlow est développé à partir de zéro, sans framework, dans le cadre de **G-RIEL IT Garden — Lab 01 : Web**.

## Le contexte

Le projet part d'un besoin concret.

Oracles doit organiser différentes activités :

* cours ;
* exercices ;
* lectures ;
* travaux pratiques ;
* projets personnels.

L'objectif n'est pas de construire une plateforme complexe de productivité, mais d'expérimenter la construction d'une petite application Web utile et cohérente.

## Fonctionnalités prévues

La première version devra permettre de :

* créer une tâche planifiée ;
* définir une date ;
* définir une heure de début et une heure de fin ;
* calculer automatiquement la durée ;
* ajouter éventuellement un objectif ;
* consulter les tâches planifiées ;
* marquer une tâche comme terminée ;
* supprimer une tâche ;
* conserver les tâches après actualisation de la page ;
* empêcher le chevauchement de plusieurs tâches.

## Approche technique

TaskFlow est développé **sans framework**.

Le projet permettra progressivement d'explorer :

* HTML ;
* CSS ;
* JavaScript ;
* DOM ;
* événements ;
* manipulation des données ;
* stockage côté navigateur ;
* responsive design ;
* debugging.

Les technologies ne constituent pas l'objectif final.

Elles sont utilisées comme des outils pour résoudre le problème concret posé par la construction de TaskFlow.
